# Demo：愿力笔记本

愿力引擎的可跑原型：**跟主Agent 聊天 → 它把你想做的事总结成文档并赋予愿力 → 文档树可嵌套可编辑 → 每个节点各自的愿力与执行。**

- **判断/对话层**默认走本机 **Claude Code 订阅**（免 API Key），也可切到 **Anthropic API**（用 Key 计费/换模型）。
- **执行层**走 Claude Code，开放 `Read/Write/Edit/Glob/Grep/Bash/WebFetch/WebSearch`；联网/`git` 由服务端代劳。
- **多工作区**：每本笔记本互相隔离，引擎跨工作区后台并行推进。

> 详细部署（依赖、两种计费模式配置、数据布局、安全、排错、后台运行）见 **[../docs/DEPLOY.md](../docs/DEPLOY.md)**。

## 前提

1. 已装 Claude Code 且用订阅登录：`claude auth status` 显示 `"authMethod": "claude.ai"`。
2. 无头订阅可用：在**普通终端**（非 Claude Code 会话内）跑 `claude -p "reply with OK"`。
   若报 403，先 `claude setup-token`（生成长效令牌供脚本用）。
3. Node.js（装了 Claude Code 就有）。

## 运行

```bash
cd demo
node server.mjs          # 打开 http://localhost:5179
```

**你只管跟主Agent 聊；愿力够了，引擎自己去干**——不用点任何按钮。

三栏界面：
- **左·笔记本树**：多节点、可嵌套，每个节点显示自己的愿力电量。
- **中·节点**：看/编辑该节点文档（人机共编）；下方「引擎动态」实时显示引擎在自动执行什么。
- **右·主Agent 对话**：你说想做什么 → 它建/改文档节点 + 赋予愿力。

服务一启动就有一个**自治引擎**常驻巡检：把「激发态」（愿力够）的笔记按愿力高低**自动**推进。**执行不扣愿力；愿力只随时间衰减**，衰减到停机线自动停（R7 定时任务引擎 + R8 停机 + R4 愿力越强越优先）。

## 试一遍

1. 右栏说：**「我想月底办一场小型线下分享会，挺上心的」** → 左栏出现节点，系统提示 `🔥 愿力 +N`。
2. 再说：**「场地要有投影，嘉宾优先本地的人」** → 它把这些合并进同一节点的文档。
3. 愿力攒够（激发）后，**引擎自动开始执行**——在中栏「引擎动态」里看它做功。执行不扣愿力；愿力随时间衰减，衰减到停机线才自动停。**你什么都不用点。**
4. 想让停掉的事继续？回右栏多跟主Agent 聊它、强调它有多重要 → 愿力回升 → 又自动开干。
5. 多说几件不同的事 → 长出多个节点，引擎按愿力高低轮着推进。

> `ledger.mjs` 顶部 `CFG` 可调阈值/半衰期/冷却间隔；`server.mjs` 顶部 `ENGINE_INTERVAL_MS` 调巡检频率。

## 文件

| 文件 | 作用 |
|------|------|
| `server.mjs` | 看板服务（HTTP + SSE） |
| `dashboard.html` | 三栏 UI |
| `brain.mjs` | 主Agent：对话 → 成文 + 赋予愿力（DESIGN §4.1） |
| `notebook.mjs` | 文档树数据模型（DESIGN §4.9） |
| `ledger.mjs` | 愿力数学：充电 / 随时间衰减 / 状态机（§2、§3） |
| `agent.mjs` | 执行器：驱动 claude 无头落地文件（§4.10/§4.11）+ 判断类 JSON 调用 |
| `notebook.json` | 运行时数据（笔记本树，gitignore） |
| `workspace/<节点id>/` | 各节点执行产物（gitignore） |

## 参数

愿力手感在 `ledger.mjs` 顶部 `CFG`：半衰期(衰减快慢) / θ_hi 激发阈 / θ_lo 停机阈 / cooldownSec 执行冷却间隔。
